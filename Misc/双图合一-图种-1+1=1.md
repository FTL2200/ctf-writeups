
> 赛事：湖州三校联赛 · 类型：Misc · 分值：123 pts
> 附件：`CTF.png`

## 题目描述

> 在常识里，1+1 应该等于 2。但如果你能打破常规，把这两样东西完美地合二为一。

## 思路分析

看到题名 **1+1=1** 和描述里的 **"合二为一"**，可能是**文件拼接 / 图种（polyglot）**：

- "1+1" → 两个文件
- "合二为一" → 拼成一个文件

也就是：**一张正常的图片里，附加了另一个隐藏文件**。这类题在 Misc 中非常经典，通常是在 PNG/JPG 的结尾（IEND 之后）追加一个 ZIP / RAR。

## 解题步骤

### 1. 基础信息检查

用 010 Editor 打开 `CTF.png`，观察文件结构：

- 开头是 `89 50 4E 47` → 确认是 **PNG**
- 正常 PNG 应以 `49 45 4E 44 AE 42 60 82`（`IEND`）结尾

### 2. 定位隐藏数据（关键）

向下滚动，在偏移 **`0000BE46`** 处发现：

`50 4B 03 04` 正是 **ZIP 文件头**（ASCII 显示为 `PK..`）。
得到的下图给AI，其言图片内藏了flag.txt
<img width="2880" height="1659" alt="image" src="https://github.com/user-attachments/assets/4737774b-86a2-4a7d-84b2-7c3b202d140d" />



说明：**PNG 的 IEND 之后，追加了一个 ZIP，里面是 `flag.txt`。**

### 3. 提取隐藏文件

**方式一：7-Zip（推荐）（我选用的方法）**

右键 `CTF.png` → **7-Zip → 打开压缩包 / 提取到当前文件夹**，自动识别内嵌 ZIP。
于是得到下图：<img width="2138" height="1230" alt="image" src="https://github.com/user-attachments/assets/4aa48f31-bbb1-4b03-ab80-b7a5023fcd19" />
，得到flag。

**方式二：010 Editor 手动提取**

1. `Edit → Select Range`，起始填 `BE46`，结束填文件末尾 `BF1D`
2. `File → Save Selection`，另存为 `hidden.zip`
3. 用 7-Zip 解压
