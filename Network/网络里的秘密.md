# 网络里的秘密

## 题目信息

| 项目 | 内容 |
|---|---|
| 题目名 | 网络里的秘密 |
| 方向 | Misc / 流量分析 |
| 附件 | traffic.pcap |

## 解题思路

```
traffic.pcap
  ↓
统计 → 协议分级，发现 HTTP + Line-based text data 占大头
  ↓
过滤器输入 http，翻请求列表
  ↓
锁定可疑包：POST /upload.php（发往外网、form-urlencoded）
  ↓
右键 → 追踪流 → HTTP 流
  ↓
请求体 content 字段里就是 flag
```

## 详细步骤

### 1. 协议分级

统计 → 协议分级，发现 `Line-based text data` 有 6 个包、11554 字节，比 PNG（9029 字节）还大，提示秘密藏在文本里。

### 2. 过滤 HTTP

显示过滤器输入 `http`，重点看第 118 号包：

```
POST /upload.php HTTP/1.1  (application/x-www-form-urlencoded)
Source:      192.168.1.100
Destination: 198.51.100.23
Length:      513
```

### 3. 追踪 HTTP 流

右键第 118 号包 → 追踪流 → HTTP 流：

```http
POST /upload.php HTTP/1.1
Host: private-notes.net
Content-Type: application/x-www-form-urlencoded
Content-Length: 78

user=admin&action=save&content=HuSec2026{719f7a2f-022b-419b-855f-77bc750f4d50}
```

## 知识点

- 流量题优先看**通信行为**，别死磕文件隐写
- 协议分级关注占比异常的协议 / 大体积文本
- 优先看 POST、含 upload/login/admin 的请求
- `Follow → HTTP Stream` 看请求体/响应体

## 常用过滤器

```
http
http.request.method == "POST"
http contains "flag"
frame contains "flag"
```
